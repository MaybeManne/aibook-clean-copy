Binary Search: O(log n)
intro

Binary search probes the middle of a sorted range and discards half of it each step. The search space collapses geometrically, not linearly.

halving
the math

Solving n / 2^k = 1 for the number of steps k:

2^k = n \implies k = \log_2 n
check

The step count is log2(n). Since 2^10 = 1024, a thousand-element array needs only about ten comparisons.

Correct. Formally the cost obeys T(n) = T(n/2) + O(1), which unrolls to O(log n): doubling the input adds exactly one comparison.
